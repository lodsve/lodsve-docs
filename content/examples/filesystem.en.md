Source code: `lodsve-boot-examples/lodsve-boot-example-filesystem`.

```bash
./mvnw -pl lodsve-boot-examples/lodsve-boot-example-filesystem spring-boot:run
```

Configure object storage endpoints, buckets, and credentials before launching. `FileSystemApplication` in the example shows the minimal Spring Boot startup method.
