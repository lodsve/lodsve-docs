Component 页面面向需要深入定制、排查行为或开发扩展的用户。普通应用优先从 Starter 页面开始。

| Component | 主要职责 | 对应 Starter |
| --- | --- | --- |
| [filesystem](/components/filesystem/) | 对象存储适配和文件生命周期 | [filesystem](/starters/filesystem/) |
| [mongodb](/components/mongodb/) | MongoDB 客户端路由和多数据源切换 | [mongodb](/starters/mongodb/) |
| [mybatis](/components/mybatis/) | Repository、分页、逻辑删除和 SQL | [mybatis](/starters/mybatis/) |
| [redis](/components/redis/) | Redis 数据源和序列化增强 | [redis](/starters/redis/) |
| [rdbms](/components/rdbms/) | 动态数据源、连接池和数据库整合 | [rdbms](/starters/rdbms/) |
| [countdown](/components/countdown/) | Redis 过期事件倒计时 | [countdown](/starters/countdown/) |
| [event](/components/event/) | 应用事件能力 | [event](/starters/event/) |
| [openfeign-client](/components/openfeign-client/) | Feign 客户端增强 | [openfeign](/starters/openfeign/) |
| [script](/components/script/) | JVM 脚本执行 | [script](/starters/script/) |
| [security](/components/security/) | 认证与授权基础能力 | [security](/starters/security/) |
| [validator](/components/validator/) | POJO 校验和异常处理 | [validator](/starters/validator/) |
| [webmvc](/components/webmvc/) | Spring WebMVC 增强 | [webmvc](/starters/webmvc/) |
