```xml
<dependency>
    <groupId>com.lodsve.boot</groupId>
    <artifactId>lodsve-boot-starter-webmvc</artifactId>
</dependency>
```

Used with Spring Boot Controller, parameter binding and exception handling. It is recommended that the business response model, exception code and request log specifications be placed at the application layer for unified constraints.
