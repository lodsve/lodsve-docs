## Choose your path

| scene | Recommended entrance | what to do next |
| --- | --- | --- |
| Create a new Maven application based on Lodsve Boot | [Maven Quickstart](/projects/lodsve-maven-archetype/quickstart/) | Select the version, generate the project, and check the generated POM and configuration |
| Create a new database, configuration center or RPC example | [Maven template directory](/projects/lodsve-maven-archetype/) | Choose MyBatis, Nacos or RPC template |
| The team already has a Gradle project template | [Gradle quick start](/projects/lodsve-gradle-archetype-plugin/getting-started/) | Prepare a local template and then pass in the project parameters |
| Generate Java constants in an existing Maven project | [Java Template](/projects/lodsve-maven-plugins/java-template/) | Configure template directory and generation phase |
| Merge resources when packaging | [Shade extension](/projects/lodsve-maven-plugins/shade/) | Configure Transformer for Maven Shade Plugin |
| Introduce basic capabilities into existing applications | [Boot quick start](/getting-started/) | Introduce BOM and required Starter |

## Version and Verification

Scaffolding version, Lodsve Boot version and Business Engineering version are three different values. When selecting a version, check the dependency coordinates generated by the template, and then verify the construction and operation of the generated project. The code examples in the document are used to illustrate the configuration method and do not mean that all combinations of templates and any Boot and JDK versions have been integrated and verified.
